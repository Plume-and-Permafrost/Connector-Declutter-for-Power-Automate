Hides connectors you cannot use from the Power Automate designer’s connector list.

What to hide

My Filter

The extension adds three filters of its own to the designer, beside All, Built-in, Shared and Custom: Microsoft, a fixed list of Microsoft’s own connectors; In Flow, what the open flow already uses — connectors and built-ins alike — which needs no setting up; and My Filter, whatever is ticked below. Unlike the filters above these hide nothing on their own — they apply only while one of them is the selected filter in the designer, and picking All puts everything back.

Loading…

This list is everything the designer has shown while the extension was watching, so it starts empty and fills in the first time you open a connector panel. A connector missing from it can be added by opening the panel and scrolling until it appears. Changes show up in the designer the next time it builds its filter list, so reload the tab if a tick does not seem to have taken.

Clear every ticked connector?

This cannot be undone, and if My Filter is the one currently selected in the designer, it will start matching nothing at all.

Panel sections

The designer stacks three collapsible sections above the connector list. Removing one is a layout choice, not a filter — everything in it is still in the list underneath and still turns up in search.

These are matched by the section’s English heading, the only thing in the designer’s markup that tells the three apart. A designer in another language keeps all three sections rather than losing the wrong one.

Appearance

Tint colours

Pick the base colour for each DLP group, and for each reason a connector would otherwise be hidden. Each is applied as a faint wash so the designer’s own styling still shows through, and lightened automatically when you are using a dark theme. A key beside the panel’s close button says which is which.

The colours below the first two only appear when Show everything is switched on in the popup — with it off, those connectors are not in the panel to be coloured.

Policy data

Import a policy by hand

Paste the response from the governance /v1/policies endpoint, a single policy, or just a list of connector IDs to block (one per line, e.g. shared_dropbox).

Configuration

Export everything — settings, filters and policy data — as one file. Admins can hand that file to makers who cannot read DLP policies themselves.

Diagnostics

Where the log appears

Every line is prefixed [declutter:…]. It is split across three consoles, because the extension runs in three places:

Designer tab
Open DevTools on make.powerautomate.com: filtering, pagination, network hooks, settings delivery and colour coding.
Admin centre tab
Open DevTools on admin.powerplatform.microsoft.com: policy capture and import.
Service worker
Go to chrome://extensions, find Connector Declutter for Power Automate and click service worker: storage, imports and refresh backoff.

Logging in the designer’s own page context only starts on the next page load after you turn this on, so reload the tab to capture start-up.

Access tokens are never logged.
